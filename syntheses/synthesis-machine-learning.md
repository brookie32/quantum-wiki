# Machine Learning: Knowledge Wiki Overview

## Current State
Machine learning continues to advance across both classical and quantum domains, with quantum machine learning (QML) emerging as a particularly active research frontier. Organizations are increasingly exploring hybrid approaches that combine quantum computing architectures with traditional ML methodologies to unlock new computational capabilities.

- **Quantum Kernel Learning (QKL)** is being experimentally extended to quantum data using NMR techniques, demonstrating practical progress beyond theoretical frameworks
- **Photonic processors** are being explored for multi-instance quantum data processing, enabling parallel loading of quantum states into QML models
