A cascaded random‑access quantum memory is realized with an eight‑bit architecture that uses a single transmon to classically address seven multimode storage resonators, separated from the processor by a buffer layer to suppress nonlinearities. The device achieves arbitrary random access with an average infidelity below 1.5 % per mode and characterizes many‑body interaction errors as the dominant source of degradation. This scalable unit cell reduces control lines per logical qubit and enables transversal operations within the memory, paving the way for fault‑tolerant quantum processors.
