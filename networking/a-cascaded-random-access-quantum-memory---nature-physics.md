Researchers demonstrated an 8-bit cascaded random access quantum memory using a buffer layer between a processor and multimode storage cavity, achieving arbitrary random access with average infidelity of approximately 1.5% per mode.   This architecture reduces control lines per logical qubit and enables transversal operations within the memory module, establishing a scalable unit cell for fault-tolerant quantum architectures.
