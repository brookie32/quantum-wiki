arXiv:2610.40904v1 Announce Type: new Abstract: Sender authentication is an important requirement for secure quantum communication networks. We propose programmable photon-echo quantum memory processing of a multi-time-bin photonic qudit for implementing a quantum-hash-based verification protocol. In this approach, using QM, sender (Alice) generates a quantum hash state by transforming a single stored photonic wave packet into the programmable photonic qudit. Bob's memory coherently maps the received time-bin photonic qudit into a single output mode according to phase encoding. Our scheme relies on a time-resolved coherent detection method introduced here, in which the coherent responses from individual time-bins are sequentially accumulated within Bob's spin coherence prior to the final sender verification. The key advantage of this coherent detection for quantum hashing is shown, and its potential applications are also discussed. The performed analysis demonstrates that experimentally verified parameters of contemporary optical quantum memories enable a proof of principle realization of the proposed architecture. These results reveal an additional role for quantum memories, serving not only as synchronization and repeater resources for long-distance quantum communication, but also as active elements for quantum hashing in conventional quantum key distribution systems.
