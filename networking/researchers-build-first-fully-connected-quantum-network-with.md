Researchers have built the world’s first fully connected quantum network using photonic microcomb technology. The system links multiple nodes via chip‑scale microresonators that generate dense optical frequency combs, enabling simultaneous creation and routing of thousands of quantum channels. This pioneering platform demonstrates a scalable architecture for large‑scale quantum communication and distributed quantum computing.
