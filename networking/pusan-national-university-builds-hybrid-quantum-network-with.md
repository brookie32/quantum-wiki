Pusan National University has successfully constructed a hybrid quantum network that links nodes using identical (indistinguishable) photons generated by on‑chip sources. The system combines photonic qubits with matter‑based memories to enable long‑distance entanglement distribution and high‑fidelity state transfer. This development represents a key step toward scalable, secure quantum communication platforms.
