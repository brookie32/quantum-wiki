arXiv:2312.16009v3 Announce Type: replace Abstract: Large-scale quantum networks enable distributed quantum tasks by sharing entanglement between distant nodes. Since entanglement distribution in such networks relies on stochastic local operations and classical communication (SLOCC), the resulting end-to-end entanglement degrades with path length and exhibits statistical variations, limiting the usable range while also making the quantification of its functional size challenging. Here, we develop a statistical framework to quantify a network's functional size by analyzing the statistics of end-to-end entanglement connections established through arbitrary entanglement-distribution protocols. This framework yields a global network metric in the form of the graph radius of viable regions up to which the distributed entanglement meets specified task thresholds. In addition to identifying absolute viable regions, within which a task is guaranteed to satisfy the prescribed thresholds, the framework identifies probabilistic viable regions, within which the task succeeds with a specified confidence. Further, it yields the viable node fraction, defined as the expected fraction of network nodes accessible from a given source node for the task, and reveals that network topology strongly influences the number of nodes contained within a network's viable region, even when the viable radii are identical. Applying the framework to quantum key distribution on random networks reveals sharp threshold behavior in the viable node fraction showing that small improvements in elementary-link quality can produce a rapid increase in the viable node fraction of the network. Viable regions in a quantum network obtained using our statistical framework therefore provide a task-oriented characterization of quantum-network functionality allowing comparison of entanglement-distribution strategies and network designs.
