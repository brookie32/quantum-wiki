arXiv:2608.06047v1 Announce Type: cross Abstract: We develop an ODE/IM-based formulation for the thermal partition function and the spectral zeta function of the homogeneous Hermitian and PT-symmetric oscillators. For both classes of systems, the quantization condition can be expressed using the counting function a(E), which can be solved via the Destri-de Vega equation of the integrable model. We then express the partition function and spectral zeta function as contour integrals involving the counting function, thereby providing a direct bridge between quantum spectral functions and integrable models.
