arXiv:2610.08890v1 Announce Type: new Abstract: Quantum numerical algorithms often encode a positive solution q in the amplitudes of a quantum state, while the required scientific output is a normalized linear functional of q. Basis measurements produce probabilities determined by squared solution values, while the functional uses the solution values themselves. We study the complexity of this output-interface problem for F_phi(q)=intphi q,mathrm dnu/int q,mathrm dnu and identify a target-dependent susceptibility hi_phi that governs the amount of copies of the solution state needed. For a fixed positive reference state and a neighborhood around it, the optimal number of unknown-state copies is Theta!left(hi_0arepsilon^{-2}log(1/eta)right), where arepsilon is the absolute error tolerance and eta is the allowed failure probability. We show that two fixed single-copy measurements attain the same rate. We then analyze how this baseline changes when the interface retains classical information, uses adaptive allocation, supplies coherent access, or restricts the allowed solution family. Therefore hi_phi quantifies a central cost of using a solution encoded in an L^2-normalized quantum state to estimate an L^1-normalized linear observable.
