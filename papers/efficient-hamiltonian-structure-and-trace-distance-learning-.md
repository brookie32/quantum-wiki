The article introduces efficient quantum‑learning protocols for positive‑temperature bosonic Gaussian states with an underlying quadratic Hamiltonian. Using only heterodyne measurements, the authors achieve a logarithmic sample complexity in the number of modes while requiring bounded temperature, squeezing, displacement and maximum graph degree. They also provide trace‑distance learning guarantees that scale quadratically with the desired precision and polynomially with system size (Nature Communications 2026).
