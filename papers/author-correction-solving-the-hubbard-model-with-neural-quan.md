In an author correction published on 21 October 2026 for the Nature Communications article *Solving the Hubbard model with neural quantum states* (originally released 22 June 2026), the authors fixed two errors: a missing μ symbol in Equation (14) of the methods section and an inaccessible Code Ocean capsule. The code‑availability statement was updated to provide functional links to the Code Ocean capsule (https://codeocean.com/capsule/8740417/tree/v1) and the full repository on GitHub, and these corrections have been applied to both the HTML and PDF versions of the paper.
