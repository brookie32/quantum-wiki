arXiv:2611.21994v1 Announce Type: new Abstract: In the set-size estimation query task, a query algorithm decides whether an N-bit input has Hamming weight ge B or le A (with ge B as the yes instances and le A as the no instances). When B = 2A, this is sometimes called approximate counting. The query complexity for this problem with a quantum witness (i.e., mathsf{QMA} query bounds) was resolved by Aaronson, Kothari, Kretschmer, and Thaler (CCC 2020) and proved using Laurent polynomials. Here we give a morally similar but distinct proof of the lower bound using the polynomial method.
