arXiv:2611.33853v1 Announce Type: new Abstract: The Generalized Geography Game (GGG) is a two-player combinatorial game played on a directed graph, where players alternately move a token along edges without revisiting previously visited vertices. In the existing literature, determining whether an arbitrary position in a graph is a winning position for either player is a well-known PSPACE-complete decision problem. Certain formulations of GGG have been shown to fall outside the PSPACE-complete complexity class. While PSPACE-complete problems are believed to take exponential time for classical computation, quantum computation offers new possibilities. In this work, we present a bounded-error quantum polynomial-time (BQP) algorithm for solving the GGG problem. The proposed algorithm runs in time O(N^{2}/epsilon^{6}), which is polynomial in the input size N, and achieves bounded error with epsilon = O(1/poly(N)). This result demonstrates the potential of quantum algorithms to efficiently solve combinatorial game problems that are traditionally considered computationally hard in the classical setting.
