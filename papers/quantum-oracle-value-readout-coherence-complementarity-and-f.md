arXiv:2607.13198v2 Announce Type: replace Abstract: A response-register quantum oracle can reveal a function value or encode it as a phase through kickback. We quantify how much value information can be recovered from one query at a fixed fidelity to a target phase character, and how noise and implementation errors affect readout performance. For pure response states over finite Abelian groups, the known covariant discrimination solution fixes the optimal readout probability exactly in terms of the ell_1-norm coherence of the response state in the character basis. Using a known coherence bound, we determine the complete pure-state readout interval at fixed target-character fidelity. Discarding the response leaves a mixture of phase-oracle channels whose distance from the target, measured by half the diamond norm, is at most the target-character infidelity, with equality for surjective functions. We then identify when coherence alone determines performance and when apparatus correlations or loss profiles are also needed. For coherent analyzer errors, we derive the full quadratic loss and an exact scalar reduction of the profile model on the upper phase--value boundary. For mode-dependent loss, no-detection events can carry value information, and a universal bound is attained under a phase--loss compatibility condition. Photonic-mesh simulations test the analyzer-error predictions, with the controlled oracle itself assumed. Selected results extend to finite non-Abelian groups, where scalar phase kickback is restricted to one-dimensional representations.
