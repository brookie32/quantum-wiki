arXiv:2608.01484v1 Announce Type: new Abstract: We explore Bloch oscillations of N=1 and N=2 photonic N00N states, using an array of linearly growing effective index waveguides with a simulated asymmetric loss profile. Starting with equal probability input N=1 and N=2 N00N states, and siphoning off a portion of the waveguides near the half Bloch period, we selectively output specific photon number states. Tuning the input phase, we achieve dynamic switching between 2-photon dominated (80% of the output) and 1-photon dominated (90% of the output) cases. This offers a path to improved state preparation in photonic circuits used in computing and networking.
