arXiv:2408.15072v4 Announce Type: replace-cross Abstract: By using the Efetov's super-symmetric formalism we computed analytically the mean spectral density rho(E) for the Levy and the Levy -Rosenzweig-Porter random matrices which off-diagonal elements are strongly non-Gaussian with power-law tails. This makes the standard Hubbard-Stratonovich transformation inapplicable to such problems. We used, instead, the functional Hubbard-Stratonovich transformation which allowed to solve the problem analytically for large sizes of matrices. We show that rho(E) depends crucially on the control parameter that drives the system through the transition between the ergodic and the fractal phases and it can be used as an order parameter.
