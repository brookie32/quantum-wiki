arXiv:2601.15945v3 Announce Type: replace Abstract: Simulations of quantum dynamics of traveling photons interacting with matter can be used to model and design photonic quantum-network components. Such simulations require selecting a finite set of photonic modes, where smaller sets are more desirable for computational efficiency. In this work, however, we show that opting for smaller subsets alters simulation results, if done naively. We therefore provide a consistency condition that can be used to calibrate the simulation input parameters to increase efficiency while preserving accuracy, simultaneously. This condition is then used to derive a simple prescription that reduces the propagation cost by two order of magnitude in a waveguide benchmark. Finally, we extend the same calibration principle to a two-dimensional atomic array, demonstrating the simultaneous benefits beyond analytically solvable waveguide models.
