arXiv:2611.14372v1 Announce Type: new Abstract: We report a physics-based matrix model for PEM fuel cell impedance that takes into account liquid water transients in the cathode catalyst layer (CCL). This model is an extension of our previous single-phase matrix model for functionally graded CCLs. The solution to the boundary-value problem for the perturbation amplitudes is constructed from basic solutions to the respective Cauchy problem with constant coefficients on numerical cells. The single-phase model employed analytical solutions to this problem. Here, for a larger system of ODEs, the analytical solution does not exist and we used spectral decomposition of the ODE system matrix to obtain the basic solutions numerically. Our impedance model is two orders of magnitude faster than a model based on a standard, general-purpose boundary-value solver. Fitting the matrix model to an experimental spectrum takes about a minute on a laptop. The developed matrix method can be used to numerically solve high-order linear boundary-value problems with variable coefficients.
