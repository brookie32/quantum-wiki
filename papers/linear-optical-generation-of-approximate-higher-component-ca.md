arXiv:2611.18065v1 Announce Type: new Abstract: We propose a method for generating higher-component cat states by interfering two N-component cat states on a half beam splitter and measuring one output with a photon-number-resolving detector. The Fock components of the conditional output are restricted to a single residue class modulo 2N. For N=3, an ideal six-component cat state can be generated exactly, while for arbitrary N, the conditional output approaches an ideal 2N-component cat state for sufficiently large input amplitudes.
