arXiv:2611.25064v1 Announce Type: new Abstract: Can a machine provably discover new quantum phases of matter? We show that the answer is yes under physically motivated assumptions. For any smooth family of geometrically local Hamiltonians, we construct an efficient quantum algorithm that outputs the phase diagram to prescribed accuracy and provides a verifiable certificate for every transition it reports. The algorithm takes as input only a classical description of the family together with unverified preparations of reference ground states; no order parameter, symmetry-breaking pattern, or training data are supplied. It succeeds provided that at least one preparation is correct in each gapped region of parameter space. The algorithm explores parameter space by quasi-adiabatically or adiabatically transporting each reference state, detecting the approach of a phase boundary by tapping the transported state with a frequency-filtered local probe: excitations created by the probe witness the closing of the energy gap. We prove that the gap closing for continuous phase transitions can always be detected using the frequency-filtered gradient of the Hamiltonian. The gap-detecting measurement is gentle, so when the ground state is unique a single reusable copy of each reference ground state supports the full exploration (for degenerate ground states, polynomially many copies suffice). The quantum algorithm runs in polynomial time at inverse-polynomial gap resolution. We also give a classical algorithm that runs in quasipolynomial time at constant gap resolution. Numerical experiments demonstrate how our algorithm accurately determines the phase structure of several model quantum systems.
