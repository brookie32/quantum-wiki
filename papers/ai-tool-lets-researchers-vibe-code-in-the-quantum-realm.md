Pasqal has created an autonomous AI agent that translates natural‑language prompts into executable quantum‑computing code and runs it on a quantum device. The tool can automate experiments that typically require seasoned quantum‑physicists, although it sometimes needs domain‑expert feedback to function correctly. By lowering the programming barrier, the system aims to broaden access to quantum computers for researchers outside specialized teams.
