arXiv:2606.09384v2 Announce Type: replace Abstract: We demonstrate that quantum algorithms can be used to model classical stochastic simulations as the measurement process is inherently random. To illustrate, we solve the classical Lorenz system with stochastic behavior using a Python random number generator. We compare the classical stochastic Lorenz system with the measured output of the quantum algorithm.
