D-Wave has launched a beta program for its gate-model quantum computing simulator, accessible via its Leap quantum cloud service. The simulator supports up to 21 qubits with both ideal and hardware emulation modes and models D-Wave's dual-rail superconducting cavity qubit architecture, which uses hardware-level error detection. The program aims to evaluate mid-circuit error detection, test real-time classical feedback control, and establish design rules for quantum machine learning algorithms under hardware noise constraints, with initial participants including financial institutions and research centers.
