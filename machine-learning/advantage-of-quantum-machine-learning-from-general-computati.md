This work constructs supervised learning tasks with classical data that demonstrate provable quantum machine learning advantage based on general quantum computational advantages, moving beyond previous approaches limited to specific algorithms like Shor's.   The learning tasks leverage functions that quantum algorithms can compute efficiently for most inputs in polynomial time but that no classical algorithm can, with proven hardness for any polynomial-time classical learning method.
