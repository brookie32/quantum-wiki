QML has recently been extended to run on C and Zig via the new libqt6 bindings, providing developers an alternative way to integrate QML into programs written in these systems programming languages. This update broadens the language support for Qt applications, allowing teams that prefer or already use C/C++ or Zig to leverage QML’s declarative UI capabilities without switching to a different toolkit. The announcement is part of ongoing efforts to make Qt more versatile across modern development stacks.
