Xanadu is demonstrating that quantum machine learning can be trained at scale. This work by Austin Huang, William Maxwell, Vasilis Belis (@VasilisBelis), Evan Peters, Jason Pye, Soran Jahangiri (@soranjh), and Joseph Bowles (@josephbowles_) uses Fourier-based methods to train a model with over 1 million parameters to accurately learn the distribution of ribosomal RNA. 🔗👇
