Marcus, Spielman, and Srivastava [MSS15] established the existence of Kadison--Singer partitions. We provide polynomial-time algorithms for the Kadison--Singer problem. For Hermitian matrices A_1,ldots,A_minmathbb C^{nimes n} of rank at most one, we give two algorithms that find signs sigmain{pm1}^m satisfying |sum_i sigma_iA_i|le C|sum_i A_i^2|^{1/2}. The deterministic algorithm achieves C=3.3443 using widetilde O(mn^2+n^{56}) arithmetic operations. The randomized algorithm achieves C=4.8628 using widetilde O(mn^2+n^{5.88}) arithmetic operations in expectation. For vectors satisfying sum_i a_ia_i^*=I and |a_i|^2lealpha, the algorithms yield partitions [m]=I_1up I_2 satisfying |sum_{iin I_j}a_ia_i^*-I/2|le (C/2)sqrtalpha for j=1,2.
