IDEMIA Secure Transactions (IST) and IonQ have successfully validated the interoperability of IonQ's Quantum Key Distribution (QKD) systems with IST's IDEMIA Sphere cybersecurity portfolio. This integration allows quantum-generated cryptographic keys to be managed within existing enterprise security controls and compliance workflows, alongside Hardware Security Modules (HSMs) and Post-Quantum Cryptography (PQC). The collaboration aims to provide quantum-safe communications for critical infrastructure without requiring organizations to replace their established security governance frameworks.
