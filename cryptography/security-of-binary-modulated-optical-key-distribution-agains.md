arXiv:2603.20395v2 Announce Type: replace Abstract: Optical key distribution (OKD) protects the physical layer of communication links by taking advantage of the inherent noise present in the photodetection process. It allows for efficient generation of a shared random key between two distant users that is secure against passive eavesdropping and can be subsequently used for cryptographic purposes. Moreover, it can be straightforwardly implemented over standard intensity modulation and direct detection links, making it an attractive alternative to quantum key distribution. Here we present a comprehensive security analysis against more powerful eavesdroppers possessing the ability to perform either coherent detection, or even quantum-optimal measurements on the intercepted transmission.
