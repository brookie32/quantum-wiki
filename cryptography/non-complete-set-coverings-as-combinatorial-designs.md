Non-complete set coverings provide a combinatorial framework for constructing threshold implementations, a masking countermeasure against side-channel attacks. For a function of algebraic degree t, a family of subsets of the input shares yields a d-th order threshold implementation if every t shares lie in a common subset and no d subsets cover all the shares. In this work we study non-complete set coverings as combinatorial designs. We introduce incomplete coverings, a family of designs that contains non-complete set coverings and is closed under the dual complement operation. We show that coverage and incompleteness are dual properties under this operation, and we define reduced incomplete coverings, which do not contain redundant blocks nor redundant elements, two notions that are dual to each other. In addition, we prove analogues for incomplete coverings of classical properties of uniform coverings. Namely, we prove the existence of derived sub-coverings, a recursion rule for covering numbers and Schönheim's bound. We use these results to improve several lower bounds on the minimal number of blocks of non-complete set coverings. Moreover, we also find new coverings and upper bounds on the covering numbers based on enhanced algorithms, in particular for degree four and order three.
