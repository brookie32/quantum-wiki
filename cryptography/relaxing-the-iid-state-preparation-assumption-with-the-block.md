arXiv:2611.21048v2 Announce Type: replace Abstract: In this work, we propose a novel approach to handling the independent and identically distributed assumption for the state preparation in prepare-and measure QKD protocols. Contrary to previous approaches, we do not prove the security using sub-protocols, and instead opt to guarantee security in the presence of correlations by dividing the communication into finite blocks of consecutive pulses, and adding an additional assumption of no dependence between each block. In turn we obtain a protocol which uses only a relaxed i.i.d. assumption and is easier to implement than subprotocol-style approaches since it does not require separate statistics for each sub-protocol, whose number grows with the correlation length of the underlying dependency.
