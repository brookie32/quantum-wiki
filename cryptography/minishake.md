The overwhelming majority of the Keccak instances standardized and used in practice today make use of the Keccak-f [1600] permutation or reduced-round versions of it. There are a few use cases where using a smaller permutation width would be beneficial, notably when one has to hash many very short messages. To address this, the present note defines instances that use the Keccak-p[800, n_r = 12] permutation, collectively under the name MiniSHAKE.
