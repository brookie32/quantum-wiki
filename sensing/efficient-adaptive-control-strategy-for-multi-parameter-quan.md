A new adaptive Hamiltonian‑control protocol is developed for multi‑parameter estimation in two‑dimensional quantum metrology systems. The method removes the usual trade‑offs among optimal measurements, initial states, and control fields by extending the system dynamics, yielding an explicit variance–time relation that can be recursively optimized at each iteration. With only a few iterations it attains near‑optimal precision (within a finite constant factor) and remains robust against inaccuracies in the applied control parameters.
