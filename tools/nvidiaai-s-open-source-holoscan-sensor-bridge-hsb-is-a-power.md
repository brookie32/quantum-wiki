Using HSB with an existing workstation, network card and cable, we saw the round-trip time from FPGA to CPU and back fall from 2.47 µs to 1.74 µs. To our knowledge, this is the lowest round-trip time for quantum control between an FPGA and a CPU over a switched network protocol.
