Infleqtion and Riverlane have partnered to integrate real-time quantum error correction with neutral-atom hardware. This collaboration aims to close the latency gap in qubit error detection and processing, enabling scalable logical qubits. They will combine Infleqtion's neutral-atom QPU and qLDPC software with Riverlane's Deltaflow decoding platform to run dynamic error correction cycles without interrupting execution.
