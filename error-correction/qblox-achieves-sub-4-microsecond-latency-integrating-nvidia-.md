Qblox has integrated its quantum system controller with NVIDIA DGX Spark and RTX PRO 6000 Blackwell GPUs using NVIDIA NVQLink, achieving real-time roundtrip latencies below 4.0 microseconds. This integration enables hardware-executed, closed-loop communication for continuous qubit parameter calibration and provides ultra-low-latency transport for quantum error correction data to GPU-based decoders. This allows for a unified development environment for quantum, AI, and classical simulation workloads that can scale from desktop units to GPU supercomputer clusters.
