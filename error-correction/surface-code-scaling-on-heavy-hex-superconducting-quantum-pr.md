This work addresses the challenge of implementing subthreshold scaling of surface-code quantum memory on IBM heavy-hex superconducting processors by co-designing code embedding and control using a SWAP-based "fold-unfold" embedding with bridge ancillas and dynamical decoupling.   The researchers demonstrate anisotropic scaling on Heron-generation devices from uniform distance-3 codes to (3,5) and (5,3) codes, showing that increasing certain code distances improves protection of logical quantum states across multiple error correction cycles.
