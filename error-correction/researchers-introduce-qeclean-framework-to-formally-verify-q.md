Researchers have developed QECLean, an open-source framework using Lean 4 to formally verify quantum error-correcting codes, addressing the difficulty of verifying complex, algorithmically discovered codes. It has successfully verified parameters for several significant QEC codes, including an IBM 360-qubit code and infinite planar code families. QECLean aims to validate AI-discovered codes and future quantum compilers by linking different mathematical representations within Lean's type system.
