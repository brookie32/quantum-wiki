In October 2026 the authors introduced a dynamic encoding‐subspace framework that allows simple linear drives to enact an error‑semi‑transparent (EsT) set of logical gates {X, H, T} on a bosonic qubit, reducing photon‑loss conditioned infidelity by fivefold and extending active‑manipulation lifetimes under quantum error correction. The approach also enables an eight‑gate composite EsT non‑Clifford operation and is compatible with detectable ancilla errors. It can be readily extended to other rotation‑symmetric bosonic codes, offering a practical route to error‑mitigated universal control using standard quantum‑control toolkits.
