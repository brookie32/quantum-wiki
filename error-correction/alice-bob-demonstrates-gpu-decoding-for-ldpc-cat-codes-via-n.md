Alice & Bob has demonstrated the GPU decoding of their LDPC-cat quantum error correction architecture using NVIDIA GPUs and the NVQLink system. This allows for microsecond-scale communication between quantum control systems and classical GPU supercomputers, enabling real-time error correction. The LDPC-cat architecture utilizes cat qubits and 2D LDPC codes to achieve low logical error rates for quantum computing.
