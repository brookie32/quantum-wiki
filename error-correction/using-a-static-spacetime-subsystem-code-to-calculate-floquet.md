arXiv:2611.33337v1 Announce Type: new Abstract: Dynamical codes, including Floquet codes, can capture time-dependent phenomena in quantum error correction circuits that are absent from static stabilizer or subsystem codes, such as detecting regions and error propagation. They are also capable of preserving more logical qubits than corresponding schemes in which the same syndrome-extraction measurements are performed without being distributed over time. However, evaluating the performance of dynamical codes is more complicated than for static codes because error detection depends on when an error occurs within the measurement schedule. In this work, we introduce a mapping from the measurement sequence of a Floquet code to a static spacetime subsystem code and show that calculating the distance of a Floquet code can be reduced to calculating the distance of the corresponding static subsystem code. Crucially, our mapping preserves code distance, a property that is not guaranteed for general spacetime code mappings. This reduction converts the dynamical distance problem into a static subsystem code problem, substantially simplifying the analysis of Floquet measurement schedules and facilitating the evaluation of fault tolerance for new measurement schemes.
