The authors introduce **directional codes**, a family of quantum LDPC (qLDPC) codes that can be implemented on standard square‑grid and certain hexagonal‑grid superconducting architectures by using iSWAP gates to perform long‑range stabiliser measurements with only local interactions. In circuit‑level simulations with a realistic superconducting Pauli noise model, the best directional code matches the logical error rate of the rotated toric code at a physical error probability \(p=10^{-3}\) while requiring roughly one‑quarter to one‑third as many physical qubits for the same number of logical qubits. This demonstrates that directional codes offer comparable fault‑tolerance performance with significantly reduced hardware overhead.
