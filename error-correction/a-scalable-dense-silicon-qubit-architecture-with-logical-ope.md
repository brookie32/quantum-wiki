arXiv:2611.33590v1 Announce Type: new Abstract: Fault-tolerant quantum computing (FTQC) requires a large number of physical qubits to encode logical qubits with sufficiently low error rates. Silicon spin qubits are a promising platform because of their small footprint, compatibility with semiconductor manufacturing technologies, and demonstrated high-fidelity operations. However, realizing a scalable architecture that supports quantum error correction, qubit transport, wiring, and logical gate operations remains a major challenge. Here, we propose a scalable dense silicon spin qubit architecture designed to support large-scale FTQC. The architecture consists of qubit memories, data qubit lanes, and cross junctions. Qubit memories store logical qubits encoded using the rotated surface code and support logical single-qubit operations. Data qubit lanes enable high-speed one-dimensional spin shuttling for connectivity between logical qubits, while cross junctions provide routing functionality and implement transversal logical CNOT gates. Using experimentally demonstrated silicon spin qubit parameters, we evaluate logical error rates as a function of code distance and estimate that a code distance of at least 21 is required to achieve logical error rates below 10^{-10} per syndrome cycle. We further analyze wiring constraints based on CMOS-compatible multiplexed control schemes and show that, with optimized wiring efficiency, more than 120,000 logical qubits could be integrated on a 100 mm imes 100 mm chip. These results provide a practical roadmap toward large-scale FTQC based on silicon spin qubit technology.
