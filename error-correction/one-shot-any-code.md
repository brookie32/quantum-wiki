arXiv:2610.02137v1 Announce Type: new Abstract: We first provide a simple proof showing that any single-shot code is self-correcting. We then show that any [[n,k]] CSS quantum low-density parity-check (QLDPC) code can be transformed into an [[nm,k]] CSS QLDPC code with single-shot (SS) quantum error correction and an efficient local decoder which runs in O(log m) parallel time. Below a constant threshold p_{rm RG}>0 for joint local stochastic physical and measurement noise, the logical failure probability over T correction rounds is bounded by egin{equation*} O(T n)exp[-Omega(m^alpha)] end{equation*} for a constant alpha>0; we say that the extit{threshold} is p_{rm RG} and extit{error suppression} is Omega(m^{alpha}). Moreover, if the input code is equipped with a single-shot decoder with threshold p_c>0 and error suppression Omega(n^{eta}), then the output code extit{enhances} the error suppression to Omega(m^{alpha} n^{eta}), while maintaining the decoder-independent threshold p_{rm RG}, and thus extit{enhanced} if p_c < p_{rm RG}.
