The authors use ZX‑calculus together with the Pauli‑web framework to analyze the injection of a $|Y\rangle$ magic state into a rotated surface code and extend earlier work by adding an expanded post‑selection section.  They also release companion code—including a PyZX 3‑D viewer—to illustrate the construction, and the paper appears on arXiv as 2501.15566v4 (2026).
