arXiv:2610.32518v1 Announce Type: new Abstract: We introduce LYNX, a quantum information processor based on trapped ^{40}Ca^+ ions. It utilizes up to 31 qubits with all-to-all connectivity. We characterize the system performance using rigorous benchmarks, such as randomized benchmarking (RB), GHZ state fidelity estimates, and quantum volume (QV) tests. The LYNX processor shows average 1-qubit gate errors of 8(5)imes 10^{-5} tested via standard RB in a 24-qubit register. An average 2-qubit gate error in a 24-qubit register of 2.84(8)imes 10^{-3} is demonstrated using interleaved RB. Furthermore, the device passes QV tests using up to 15 qubits which corresponds to a quantum volume of QV=2^{15}.
