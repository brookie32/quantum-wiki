arXiv:2610.03377v1 Announce Type: new Abstract: Marriott and Watrous showed that quantum Merlin--Arthur games admit generic error reduction without increasing witness size [Computational Complexity, 2005]. In this work, we show that this state-size-preserving amplification property does not hold for polynomial-time quantum computation with quantum advice. In particular, we present decision problems for which even a vanishing additive error reduction requires longer advice. More precisely, for every polynomially bounded advice length m(n)geq n^4 and every error bound arepsilon(n) that stays below 1/2 by at least an inverse polynomial, there is a positive function elta with elta(n)=Oigl(min{(log m/m)^{1/4}, sqrt{log m/m},/(1/2-arepsilon(n))}igr) such that mathsf{BQP}_{arepsilon}/mathsf{q}m subsetneq mathsf{BQP}_{arepsilon + elta}/mathsf{q}m; for constant arepsilon the gap is O(sqrt{log m/m}). Here, mathsf{BQP}_arepsilon/mathsf{q}m is the class of languages recognizable with error at most arepsilon(n) by a polynomial-time quantum algorithm with an m(n)-qubit advice state that only depends on the input length n. We show this by proving a stronger separation mathsf{P}_{arepsilon+elta}/mathsf{r} m notsubset mathsf{BQP}_{arepsilon}/mathsf{q} m, where mathsf{P}_{arepsilon}/mathsf{r}m is the class of languages recognizable with error at most arepsilon(n) by a deterministic polynomial-time algorithm with an m(n)-bit advice string sampled from a distribution that depends only on n.
