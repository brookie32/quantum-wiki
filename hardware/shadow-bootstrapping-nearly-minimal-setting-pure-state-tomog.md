arXiv:2611.06073v1 Announce Type: new Abstract: We present a pure-state tomography algorithm that uses a nearly minimal number of measurement settings while achieving optimal sample complexity with nonadaptive single-copy shallow Clifford measurements. For an arbitrary n-qubit pure state |psirangle in C^{d}, where d=2^n, the algorithm uses O(d/epsilon) copies and widetilde{O}(1) measurement settings to output a state vector |hat{psi}rangle satisfying 1-|langlepsi|hat{psi}rangle|^2leepsilon with high probability. Each measurement is implemented by a Clifford circuit of depth O(log n). Reusing each measurement setting allows the data to be stored compactly as per-basis outcome histograms. Given these histograms, classical post-processing runs in widetilde{O}(d) time. Our key technique, extit{shadow bootstrapping}, uses the current estimate to reduce the variance of subsequent residual estimation, enabling progressively more accurate reconstruction with only a constant number of new measurement settings per stage.
