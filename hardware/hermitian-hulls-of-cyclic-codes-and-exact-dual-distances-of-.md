arXiv:2607.12242v3 Announce Type: replace-cross Abstract: Let C be an [n,k,d] linear code over F_{q^2} with parity-check matrix H. The rank r=Rank(HH^{agger}) measures how far the Hermitian dual C^{perp_h} is from being Hermitian self-orthogonal, and it is the least number of coordinates that must be adjoined to C^{perp_h} to make it Hermitian self-orthogonal; equivalently, the Hermitian hull CapC^{perp_h} has dimension (n-k)-r. In this paper, we develop a structure theory of the Hermitian hull of a cyclic code and apply it to the construction of quantum stabilizer codes. For a cyclic code with defining set TsubseteqZ_n, we show that r is additive over the orbits of the involution au(nu)=-qnu on the q^2-cyclotomic cosets and satisfies a parity constraint. A parameter dictionary exhibits r as a gauge trading one-for-one against the code length, and a complementation duality shows that the complement of T realises the logical-qubit count of the quantum code. The extreme values of r are settled by closed subset-sum criteria, and the au-invariant defining sets are shown to be the unique locus on which the Hermitian dual is again cyclic. On the distance side, we determine the Hermitian dual distance of an r-fold extension of an arbitrary linear code exactly, and we prove that the admissible extension vectors lie in the image of HH^{agger}, which reduces the search space from q^{2(n-k)} to q^{2r}. Applied to cyclic, quasi-cyclic and BCH codes, the construction improves 23 best-known parameters in Grassl's code tables, one of them provably optimal.
