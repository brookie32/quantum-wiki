arXiv:2603.13169v3 Announce Type: replace Abstract: It is known that a computationally universal gate set {H,CCZ} can be transformed to a strictly universal one {H, Lambda(S)} using one maximally imaginary state |+i rangle and non-imaginary ancillary qubits. We succeed this transformation with a shorter circuit that eliminates non-imaginary ancillary qubits. We further extend this to the continuous gate-set setting, showing that any multi-qubit unitary can be exactly generated by real single-qubit unitary gates, CCZ gates and |0 rangle |+i rangle.
