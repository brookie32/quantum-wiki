I'll search for information about this open-source Python package for analyzing superconducting quantum circuits. scqubits is an open-source Python package for simulating and analyzing superconducting circuits.   It provides convenient routines to obtain energy spectra of common superconducting qubits such as the transmon and fluxonium, and features options for visualizing spectral data including plots of energy levels and qubit wavefunctions.   The library also provides an extensive suite of methods for estimating qubit coherence times due to various noise channels.
