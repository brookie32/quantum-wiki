Standard Boolean logic gates like AND and OR are irreversible—knowing only the output makes it impossible to determine the original inputs .  To make Boolean computation reversible, additional "garbage" information about the intermediate computation must be stored in extra output lines, requiring more input and output lines than traditional gates .  The key technique involves preserving logical inputs in the outputs by copying them unchanged, then combining results with auxiliary bits using binary arithmetic modulo two .
