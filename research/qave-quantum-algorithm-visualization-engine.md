QAVE is a scientifically rigorous quantum circuit and algorithm visualization engine built for teaching and conceptual clarity.   The Python backend emits trace data with physically computed in-gate evolution samples, and the reference viewer replays traces deterministically with synchronized views using a Processing Java-mode sketch.
