I'll search for information about this project to provide an accurate summary. mlxQ is a quantum simulation framework built around Apple Silicon's unified memory architecture, productized through the osxQuantum project published in an IEEE QSYS paper.   Unlike most high-performance quantum simulators optimized for CUDA and discrete GPU memory, mlxQ leverages Apple Silicon's unified memory pool where CPU and GPU share one address space, removing explicit host-device copy overhead.   The framework supports state-vector quantum algorithms including QFT, QAOA, Hamiltonian simulation, and Grover's algorithm with validated performance across multiple qubit scales.
