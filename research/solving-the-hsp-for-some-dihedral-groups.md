The hidden subgroup problem (HSP) is a cornerstone problem in quantum computing that provides a standard framework for studying problems using Fourier sampling techniques, which succeeds for some groups but not others.   The dihedral group is one of the simplest non-abelian groups, but from the HSP perspective, it has remained a difficult case.   A polynomial time quantum algorithm for solving the HSP on dihedral groups would imply a polynomial time algorithm to solve certain hard lattice problems considered intractable using classical computers.
